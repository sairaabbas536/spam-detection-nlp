# Email/SMS Spam Detection with NLP 📩

An NLP-based binary classifier that distinguishes spam messages from 
legitimate (ham) messages using TF-IDF features and machine learning.

## Tech Stack
- Python, pandas, scikit-learn (TF-IDF, Naive Bayes, Logistic Regression)
- NLTK (text preprocessing), WordCloud, Google Colab

## Dataset
SMS Spam Collection Dataset (5,574 labeled SMS messages)

## What's Included
- Class distribution analysis (spam vs. ham)
- Text preprocessing (lowercase, punctuation/stopword removal, lemmatization)
- TF-IDF feature extraction
- 2 trained classifiers: Naive Bayes, Logistic Regression
- Evaluation: accuracy, precision, recall, F1-score, confusion matrix
- Discussion on why recall is important for spam detection
- WordCloud visualizations for spam vs. ham vocabulary

## How to Run
Open `spam_detection.ipynb` in Google Colab and click "Run all".
